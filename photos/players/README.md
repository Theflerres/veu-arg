# Fotos do Scanner de Players

Largue aqui os arquivos de imagem dos players (`.png`, `.jpg`, `.jpeg`,
`.webp`, `.gif`, `.avif`). Eles entram no loop do Scanner automaticamente —
não é preciso editar nenhum componente.

A ordem do loop é a ordem alfabética dos nomes dos arquivos, então nomear
como `01-fulano.png`, `02-ciclano.png` ... dá controle sobre a sequência.

Enquanto a pasta estiver vazia, o Scanner roda com silhuetas de placeholder
(definidas em `src/app/scanner-data.ts`).
